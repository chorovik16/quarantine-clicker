# 🖼 Зразки шаблонів (OpenCV Templates)

У цю папку (або в корінь проєкту) помістіть знімки цільових ігрових елементів для порівняння через OpenCV `matchTemplate`:

* `button_home.png` — Іконка або кнопка входу в «Домик» (сховище).
* `drink.png` — Зображення основного відновлювального напою (Енергетик) в інвентарі.
* `kvas.png` — Зображення альтернативного напою (Квас) в інвентарі.
* `no_energy.png` — Візуальний маркер або діалогове вікно вичерпання енергії персонажа.
* `no_supplies.png` — Візуальний маркер або діалогове вікно закінчення припасів для фарму.

> 💡 **Порада**: Робіть скріншоти в масштабі 1:1 без спотворень та масштабування інтерфейсу браузера (100% Zoom).
